# 单链表的完整实现：从原理到C语言实战

> 作者：蔡浩宇 | 数据结构与算法笔记

## 引言

链表是最基础的动态数据结构之一。相比数组，链表不需要连续内存空间，插入和删除操作的时间复杂度为O(1)。在嵌入式系统中（尤其是内存受限场景），链表常用于管理动态任务队列、消息缓冲区和设备列表。本文将从零开始实现一个功能完整的单链表，并讨论其实际应用场景。

---

## 1. 链表基本概念

### 1.1 链表 vs 数组

```
数组（连续内存）：
┌───┬───┬───┬───┬───┐
│ A │ B │ C │ D │ E │
└───┴───┴───┴───┴───┘
  0   1   2   3   4  ← 连续索引，随机访问O(1)

单链表（离散内存）：
┌───┐    ┌───┐    ┌───┐    ┌───┐
│ A │───►│ B │───►│ C │───►│ D │───► NULL
└───┘    └───┘    └───┘    └───┘
                                    插入/删除O(1)
                                    随机访问O(n)
```

| 操作 | 数组 | 链表 |
|------|------|------|
| 随机访问 | O(1) | O(n) |
| 头部插入 | O(n) | O(1) |
| 中间插入 | O(n) | O(n)（查找）+ O(1)（插入） |
| 内存开销 | 固定 | 每节点多一个指针 |

## 2. 数据结构定义

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

/* 链表节点定义 */
typedef struct ListNode {
    int data;               // 数据域
    struct ListNode *next;   // 指针域（指向下一个节点）
} ListNode;

/* 链表结构定义（带头节点） */
typedef struct {
    ListNode *head;         // 头指针
    int size;                // 链表长度
} LinkedList;
```

> **设计选择**：本文采用"带头节点"的设计。头节点的 data 域不存储有效数据，其 next 指向第一个实际数据节点。优点是插入/删除操作时无需特殊处理头部。

## 3. 核心操作实现

### 3.1 初始化与创建节点

```c
/* 创建新节点 */
ListNode *ListNode_Create(int data)
{
    ListNode *node = (ListNode *)malloc(sizeof(ListNode));
    if (node == NULL)
    {
        fprintf(stderr, "Memory allocation failed!\n");
        return NULL;
    }
    node->data = data;
    node->next = NULL;
    return node;
}

/* 初始化链表 */
void LinkedList_Init(LinkedList *list)
{
    list->head = ListNode_Create(0);  // 创建头节点（data=0, 无意义）
    list->size = 0;
}
```

### 3.2 头部插入（O(1)）

```c
void LinkedList_InsertHead(LinkedList *list, int data)
{
    ListNode *new_node = ListNode_Create(data);
    new_node->next = list->head->next;
    list->head->next = new_node;
    list->size++;
}
```

### 3.3 尾部插入（O(n)→可优化为O(1)）

```c
void LinkedList_InsertTail(LinkedList *list, int data)
{
    ListNode *new_node = ListNode_Create(data);

    /* 找到尾节点 */
    ListNode *cur = list->head;
    while (cur->next != NULL)
    {
        cur = cur->next;
    }

    cur->next = new_node;
    list->size++;
}
```

### 3.4 按值查找

```c
ListNode *LinkedList_Find(LinkedList *list, int data)
{
    ListNode *cur = list->head->next;  // 跳过头节点
    while (cur != NULL)
    {
        if (cur->data == data)
        {
            return cur;
        }
        cur = cur->next;
    }
    return NULL;  // 未找到
}
```

### 3.5 删除节点

```c
int LinkedList_Delete(LinkedList *list, int data)
{
    ListNode *prev = list->head;
    ListNode *cur  = list->head->next;

    while (cur != NULL)
    {
        if (cur->data == data)
        {
            prev->next = cur->next;  // 跳过当前节点
            free(cur);                // 释放内存
            list->size--;
            return 1;  // 删除成功
        }
        prev = cur;
        cur  = cur->next;
    }
    return 0;  // 未找到
}
```

### 3.6 反转链表（经典面试题）

```c
/* 迭代法反转链表 */
void LinkedList_Reverse(LinkedList *list)
{
    ListNode *prev = NULL;
    ListNode *cur  = list->head->next;
    ListNode *next = NULL;

    while (cur != NULL)
    {
        next = cur->next;   // 暂存下一个节点
        cur->next = prev;   // 反转指针方向
        prev = cur;         // prev前进一步
        cur  = next;        // cur前进一步
    }

    list->head->next = prev;  // 头节点指向新的第一个节点
}
```

## 4. 完整测试代码

```c
void LinkedList_Print(LinkedList *list)
{
    ListNode *cur = list->head->next;
    printf("List[%d]: ", list->size);
    while (cur != NULL)
    {
        printf("%d -> ", cur->data);
        cur = cur->next;
    }
    printf("NULL\n");
}

void LinkedList_Destroy(LinkedList *list)
{
    ListNode *cur = list->head;
    while (cur != NULL)
    {
        ListNode *temp = cur;
        cur = cur->next;
        free(temp);
    }
    list->head = NULL;
    list->size = 0;
}

int main(void)
{
    LinkedList list;
    LinkedList_Init(&list);

    /* 头部插入 */
    LinkedList_InsertHead(&list, 30);
    LinkedList_InsertHead(&list, 20);
    LinkedList_InsertHead(&list, 10);
    LinkedList_Print(&list);  // List[3]: 10 -> 20 -> 30 -> NULL

    /* 尾部插入 */
    LinkedList_InsertTail(&list, 40);
    LinkedList_InsertTail(&list, 50);
    LinkedList_Print(&list);  // List[5]: 10 -> 20 -> 30 -> 40 -> 50 -> NULL

    /* 查找 */
    ListNode *found = LinkedList_Find(&list, 30);
    printf("Find 30: %s\n", found ? "Found" : "Not found");

    /* 删除 */
    LinkedList_Delete(&list, 20);
    LinkedList_Print(&list);  // List[4]: 10 -> 30 -> 40 -> 50 -> NULL

    /* 反转 */
    LinkedList_Reverse(&list);
    LinkedList_Print(&list);  // List[4]: 50 -> 40 -> 30 -> 10 -> NULL

    /* 销毁 */
    LinkedList_Destroy(&list);

    return 0;
}
```

## 5. 嵌入式应用：任务链表

在嵌入式系统中，链表常用于管理动态任务队列：

```c
typedef enum { TASK_IDLE, TASK_READY, TASK_RUNNING, TASK_DONE } TaskState;

typedef struct TaskNode {
    void (*func)(void);     // 任务函数指针
    TaskState state;
    uint32_t period;        // 执行周期(ms)
    uint32_t last_run;      // 上次执行时间
    struct TaskNode *next;
} TaskNode;

/* 任务调度器遍历链表执行任务 */
void TaskScheduler_Run(TaskNode *head)
{
    TaskNode *cur = head;
    while (cur != NULL)
    {
        if (cur->state == TASK_READY &&
            (HAL_GetTick() - cur->last_run >= cur->period))
        {
            cur->func();              // 执行任务
            cur->last_run = HAL_GetTick();
        }
        cur = cur->next;
    }
}
```

## 6. 常见变种

| 变种 | 特点 | 应用 |
|------|------|------|
| 双向链表 | 每节点有 prev + next | 浏览器前进/后退 |
| 循环链表 | 尾节点指向头节点 | 操作系统进程调度 |
| 带尾指针的链表 | 维护 tail 指针 | FIFO队列O(1)入队出队 |
