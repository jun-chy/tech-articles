# STM32定时器全解：从基本定时到PWM输出的工程实践

> 作者：蔡浩宇 | 嵌入式开发笔记

## 引言

如果说GPIO是STM32的"手脚"，那么定时器就是它的"心脏"——几乎所有需要精确时间控制的功能都离不开它。从简单的毫秒延时到复杂的PWM电机驱动，从输入捕获测量频率到编码器接口读取位置，定时器贯穿嵌入式开发的方方面面。本文将系统梳理STM32定时器的分类、工作模式及HAL库配置，并以PWM控制舵机为例展示完整工程实践。

---

## 1. STM32定时器家族

### 1.1 三级分类体系

| 类型 | 典型型号 | 位数 | 通道数 | 核心特性 |
|------|---------|------|--------|---------|
| **基本定时器** | TIM6/TIM7 | 16位 | 0 | 仅时基单元，用作DAC触发或简单延时 |
| **通用定时器** | TIM2~TIM5 | 16/32位 | 4 | 输入捕获、输出比较、PWM、编码器接口 |
| **高级定时器** | TIM1/TIM8 | 16位 | 6+互补 | 死区插入、刹车输入、三相电机控制 |

**选型口诀**：简单延时用基本，常规PWM用通用，电机驱动用高级。

### 1.2 时钟源与分频树

```
系统时钟 SYSCLK (72MHz for STM32F103)
    │
    ├─ AHB Prescaler ────────────────────────────► HCLK (72MHz)
    │
    ├─ APB1 Prescaler (/2) ──────────────────────► PCLK1 (36MHz)
    │       │
    │       └─► 若APB1 Prescaler ≠ 1，则 TIMx_CLK = PCLK1 × 2 = 72MHz
    │
    └─ APB2 Prescaler (/1) ──────────────────────► PCLK2 (72MHz)
            │
            └─► TIM1/TIM8 时钟 = 72MHz
```

**关键细节**：STM32F103中，APB1预分频器为/2时，挂载在APB1上的定时器时钟会自动×2，保证TIM2~TIM7实际工作频率仍为72MHz。

## 2. 时基单元：定时器的"心跳"

### 2.1 核心寄存器

```
                    ┌──────────────────────────────────────────┐
                    │         时基单元 (Time-Base Unit)          │
                    │                                          │
  TIMx_CLK ──────► │  ┌──────────┐    ┌──────────┐           │
                    │  │ Prescaler│───►│  Counter │───► 更新事件 │
                    │  │  (PSC)   │    │  (CNT)   │    (UEV)   │
                    │  └──────────┘    └────┬─────┘           │
                    │                      │                  │
                    │                 ┌────▼─────┐            │
                    │                 │  Auto-   │            │
                    │                 │  Reload  │            │
                    │                 │  (ARR)   │            │
                    │                 └──────────┘            │
                    └──────────────────────────────────────────┘
```

### 2.2 定时周期计算公式

```
定时器时钟频率  = TIMx_CLK / (PSC + 1)
溢出周期        = (ARR + 1) × (PSC + 1) / TIMx_CLK

示例：72MHz时钟，产生1ms中断
PSC = 72 - 1 = 71      → 分频后 = 72MHz / 72 = 1MHz（即1us计数一次）
ARR = 1000 - 1 = 999    → 1000次计数后溢出 = 1ms
```

### 2.3 HAL库配置模板

```c
/* 定时器1ms中断初始化 */
TIM_HandleTypeDef htim2;

void Timer2_Init(void)
{
    __HAL_RCC_TIM2_CLK_ENABLE();  // 使能时钟

    htim2.Instance = TIM2;
    htim2.Init.Prescaler         = 71;       // 72MHz / (71+1) = 1MHz
    htim2.Init.CounterMode       = TIM_COUNTERMODE_UP;
    htim2.Init.Period            = 999;      // 1MHz / (999+1) = 1kHz → 1ms
    htim2.Init.ClockDivision     = TIM_CLOCKDIVISION_DIV1;
    htim2.Init.AutoReloadPreload = TIM_AUTORELOAD_PRELOAD_ENABLE;

    HAL_TIM_Base_Init(&htim2);
    HAL_TIM_Base_Start_IT(&htim2);           // 启动定时器+使能中断

    HAL_NVIC_SetPriority(TIM2_IRQn, 1, 0);   // 配置中断优先级
    HAL_NVIC_EnableIRQ(TIM2_IRQn);
}

/* 中断服务函数 */
void TIM2_IRQHandler(void)
{
    HAL_TIM_IRQHandler(&htim2);
}

/* 溢出回调 */
void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
    if (htim->Instance == TIM2)
    {
        /* 每1ms执行一次 */
        static uint32_t tick = 0;
        tick++;
        if (tick >= 500)       // 500ms翻转LED
        {
            tick = 0;
            HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
        }
    }
}
```

## 3. PWM输出：从波形到控制

### 3.1 PWM核心参数

```
频率 (Frequency)  = TIMx_CLK / [(PSC + 1) × (ARR + 1)]
占空比 (Duty)     = CCR / (ARR + 1) × 100%
分辨率 (Resolution)= log₂(ARR + 1) bit

典型值（舵机控制）：
频率 = 50Hz → 周期 = 20ms
PSC = 72 - 1 = 71, ARR = 20000 - 1 = 19999
占空比范围：500us~2500us → CCR = 500~2500 (对应0°~180°)
```

### 3.2 输出比较模式对比

```
PWM模式1：CNT < CCR → 有效电平，CNT >= CCR → 无效电平
PWM模式2：CNT < CCR → 无效电平，CNT >= CCR → 有效电平（互补）

图形示意（PWM模式1，向上计数）：
    ARR ─ ┌──────────┬──────────┐
          │          │          │
    CCR ─ │    ┌─────┤    ┌─────┤
          │    │     │    │     │
      0 ─ ┘    └─────┘    └─────┘
          ├────────┤├───┤
          高电平    低电平
          ← 占空比 = CCR/ARR × 100%
```

### 3.3 舵机控制完整工程

```c
/* PWM初始化——TIM3_CH1 (PA6) 输出50Hz PWM */
TIM_HandleTypeDef htim3;

void PWM_Servo_Init(void)
{
    __HAL_RCC_TIM3_CLK_ENABLE();
    __HAL_RCC_GPIOA_CLK_ENABLE();

    /* GPIO配置：复用推挽输出 */
    GPIO_InitTypeDef gpio = {
        .Pin       = GPIO_PIN_6,
        .Mode      = GPIO_MODE_AF_PP,
        .Pull      = GPIO_NOPULL,
        .Speed     = GPIO_SPEED_FREQ_LOW,
        .Alternate = GPIO_AF2_TIM3
    };
    HAL_GPIO_Init(GPIOA, &gpio);

    /* 定时器配置：50Hz PWM */
    htim3.Instance = TIM3;
    htim3.Init.Prescaler         = 71;       // 72MHz / 72 = 1MHz
    htim3.Init.CounterMode       = TIM_COUNTERMODE_UP;
    htim3.Init.Period            = 19999;    // 1MHz / 20000 = 50Hz
    htim3.Init.ClockDivision     = TIM_CLOCKDIVISION_DIV1;
    HAL_TIM_PWM_Init(&htim3);

    /* PWM通道配置 */
    TIM_OC_InitTypeDef oc = {
        .OCMode     = TIM_OCMODE_PWM1,
        .Pulse      = 1500,      // 初始位置：1.5ms → 90° (中位)
        .OCPolarity = TIM_OCPOLARITY_HIGH,
        .OCFastMode = TIM_OCFAST_DISABLE
    };
    HAL_TIM_PWM_ConfigChannel(&htim3, &oc, TIM_CHANNEL_1);
    HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);
}

/* 角度控制函数（0°~180°） */
void Servo_SetAngle(uint8_t angle)
{
    if (angle > 180) angle = 180;

    /* 将0°~180°映射到500~2500（CCR值） */
    uint16_t pulse = 500 + (uint16_t)(angle * 2000UL / 180);

    __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, pulse);
}

/* 平滑转动：分步到达目标角度 */
void Servo_SmoothMove(uint8_t target, uint16_t step_delay_ms)
{
    uint16_t current = __HAL_TIM_GET_COMPARE(&htim3, TIM_CHANNEL_1);
    uint16_t target_pulse = 500 + (uint16_t)(target * 2000UL / 180);

    if (current < target_pulse)
    {
        for (; current <= target_pulse; current += 10)
        {
            __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, current);
            HAL_Delay(step_delay_ms);
        }
    }
    else
    {
        for (; current >= target_pulse; current -= 10)
        {
            __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, current);
            HAL_Delay(step_delay_ms);
        }
    }
}
```

## 4. 输入捕获：测量外部信号

### 4.1 工作原理

```
                     ┌──────────────────┐
外部信号 ──────────► │ 边沿检测         │
                     │ (上升/下降/双边) │
                     └────────┬─────────┘
                              │
                              ▼
                     ┌──────────────────┐
                     │ 捕获当前CNT值     │────► CCRx 寄存器
                     │ 存入CCRx          │
                     └──────────────────┘
                              │
                              ▼
                     ┌──────────────────┐
                     │ 两次捕获值相减    │────► 脉冲宽度 / 周期
                     │ Δ = CCR2 - CCR1  │
                     └──────────────────┘
```

### 4.2 频率测量：PWM输入模式

```c
/* 使用TIM2_CH1 (PA0) 测量输入信号频率 */
TIM_HandleTypeDef htim2_ic;
volatile uint32_t input_freq_hz = 0;

void InputCapture_Init(void)
{
    __HAL_RCC_TIM2_CLK_ENABLE();

    htim2_ic.Instance = TIM2;
    htim2_ic.Init.Prescaler     = 71;        // 1MHz计数
    htim2_ic.Init.CounterMode   = TIM_COUNTERMODE_UP;
    htim2_ic.Init.Period        = 0xFFFF;    // 最大65535
    htim2_ic.Init.ClockDivision = TIM_CLOCKDIVISION_DIV1;
    HAL_TIM_IC_Init(&htim2_ic);

    /* 配置为PWM输入模式（CH1捕获上升沿，CH2捕获下降沿） */
    TIM_IC_InitTypeDef ic = {
        .ICPolarity  = TIM_ICPOLARITY_RISING,
        .ICSelection = TIM_ICSELECTION_DIRECTTI,
        .ICPrescaler = TIM_ICPSC_DIV1,
        .ICFilter    = 0
    };
    HAL_TIM_IC_ConfigChannel(&htim2_ic, &ic, TIM_CHANNEL_1);

    /* CH2自动配置为间接输入，捕获下降沿 */
    ic.ICPolarity  = TIM_ICPOLARITY_FALLING;
    ic.ICSelection = TIM_ICSELECTION_INDIRECTTI;
    HAL_TIM_IC_ConfigChannel(&htim2_ic, &ic, TIM_CHANNEL_2);

    HAL_TIM_IC_Start_IT(&htim2_ic, TIM_CHANNEL_1);
    HAL_TIM_IC_Start_IT(&htim2_ic, TIM_CHANNEL_2);
}

void HAL_TIM_IC_CaptureCallback(TIM_HandleTypeDef *htim)
{
    static uint32_t rising_edge  = 0;
    static uint32_t period_ticks = 0;

    if (htim->Channel == HAL_TIM_ACTIVE_CHANNEL_1)
    {
        /* 上升沿：记录时间戳，计算频率 */
        uint32_t now = HAL_TIM_ReadCapturedValue(htim, TIM_CHANNEL_1);
        if (rising_edge != 0)
        {
            period_ticks = now - rising_edge;
            if (period_ticks > 0)
                input_freq_hz = 1000000 / period_ticks;  // 1MHz 时钟
        }
        rising_edge = now;
    }
}
```

## 5. 高级定时器：电机控制专属

### 5.1 互补输出与死区

```
高级定时器特有的双通道互补输出：

CH1  ────┐     ┌─────┐     ┌─────
          │     │     │     │
CH1N ────┘     └─────┘     └─────
          ├─────┤
          死区时间 (Dead Time)

目的：防止H桥上下臂同时导通导致短路
死区时间 = DTG × t_DTS  (通常设置100ns~2us)
```

### 5.2 刹车功能（Break）

```c
/* 配置刹车输入——紧急情况立即关闭所有PWM输出 */
TIM_BreakDeadTimeConfigTypeDef bd = {
    .OffStateRunMode  = TIM_OSSR_ENABLE,
    .OffStateIDLEMode = TIM_OSSI_ENABLE,
    .LockLevel        = TIM_LOCKLEVEL_OFF,
    .DeadTime         = 72,           // 72 × 13.89ns ≈ 1us (72MHz时)
    .BreakState       = TIM_BREAK_ENABLE,
    .BreakPolarity    = TIM_BREAKPOLARITY_HIGH,
    .BreakFilter      = 0,
    .Break2State      = TIM_BREAK2_DISABLE,
    .Break2Polarity   = TIM_BREAK2POLARITY_HIGH,
    .Break2Filter     = 0,
    .AutomaticOutput  = TIM_AUTOMATICOUTPUT_ENABLE
};
HAL_TIMEx_ConfigBreakDeadTime(&htim1, &bd);
```

## 6. 实战对比：三种生成PWM的方式

| 方式 | 精度 | CPU占用 | 适用场景 |
|------|------|---------|----------|
| **定时器PWM硬件输出** | 高（16位分辨率） | 极低（硬件自动） | 电机控制、LED调光、音频生成 |
| **定时器中断+GPIO翻转** | 中（中断延迟不确定） | 高（频繁ISR） | 低频简单波形、学习验证 |
| **DMA+PWM** | 高 | 极低 | RGB灯带(WS2812)、任意波形生成 |

### 推荐实践

- **LED呼吸灯** → 定时器PWM硬件输出（占空比线性变化）
- **舵机控制** → 50Hz定时器PWM（标准伺服协议）
- **WS2812灯带** → DMA+PWM（需要精确到ns级别的时序）
- **两相步进电机** → 高级定时器互补输出+死区

## 7. 常见陷阱与调试技巧

### 7.1 三大经典问题

```c
/* 陷阱1：忘记使能AFIO时钟（F1系列） */
// 错误：直接配置GPIO复用功能
// 正确：
__HAL_RCC_AFIO_CLK_ENABLE();  // F1必须使能！

/* 陷阱2：PWM已配置但无输出 */
// 检查清单：
// 1. HAL_TIM_PWM_Start() 是否调用？
// 2. GPIO_Mode 是否为 GPIO_MODE_AF_PP？
// 3. GPIO_Alternate 是否正确？
// 4. 对应通道的CCR值是否 > 0？

/* 陷阱3：中断频率过高导致系统卡死 */
// ARR=99, PSC=0, TIMx_CLK=72MHz
// → 中断频率 = 72MHz / 100 = 720kHz!
// → CPU完全无法处理其他任务
// 解决：合理设置PSC和ARR，使中断频率 ≤ 10kHz
```

### 7.2 调试利器：逻辑分析仪验证

在没有示波器的情况下，使用廉价逻辑分析仪（如Saleae Logic 8克隆版）配合 PulseView 软件，可以直观验证PWM频率和占空比，是嵌入式开发中性价比最高的调试方案之一。

## 总结

本文覆盖了STM32定时器从基础时基到高级PWM输出的完整知识链：

- **基本定时器**：延时、时基触发
- **PWM输出**：舵机/电机控制、LED调光
- **输入捕获**：频率/脉宽测量
- **高级定时器**：互补输出、死区、刹车

定时器是嵌入式系统时序控制的核心。掌握其原理与HAL库配置方法后，可进一步探索编码器模式、定时器级联、从模式触发等进阶功能，为复杂项目奠定扎实的时序控制基础。
